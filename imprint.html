4. Art des Projekts / Nature of the Project

Dieses Projekt ("TrainerTrials" / "Catchmon Arena") wird von einer Privatperson als Freizeitprojekt betrieben. Es handelt sich um ein interaktives Spiel, das im Rahmen von Live-Streams auf der Plattform TikTok stattfindet.

This project ("TrainerTrials" / "Catchmon Arena") is operated by a private individual as a leisure project. It consists of an interactive game played during live streams on the TikTok platform.

Hinweis zur wirtschaftlichen Tätigkeit:
Im Rahmen von TikTok-Live-Streams können Zuschauer Geschenke ("Gifts") über die TikTok-Plattform senden. Diese Geschenke werden von TikTok verarbeitet und unterliegen ausschließlich den Nutzungsbedingungen und dem Abrechnungssystem von TikTok. Der Betreiber erhält ggf. eine Vergütung durch TikTok auf Basis der eingegangenen Gifts. Diese Tätigkeit wird steuerlich als sonstige Einkünfte behandelt und ggf. versteuert.
