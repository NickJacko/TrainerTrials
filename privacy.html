2. Data Collected

The following data is collected when users interact with the live stream:

  • TikTok username of users who send likes
  • Number of likes sent per user
  • Amount of donations and donor usernames
No additional personal data such as IP addresses, device IDs or cookies are collected.

3. Purpose of Data Processing

The data is collected and processed solely for the purpose of displaying real-time catch statistics, rankings, and interactive feedback within the stream and on the associated Catchmon web pages.

4. Storage and Hosting

All data is stored as JSON files within the public GitHub repository that hosts this website. The repository does not contain sensitive personal data beyond publicly available TikTok usernames.

5. Legal Basis

Data processing is based on Art. 6 (1) lit. f GDPR (legitimate interest) to operate an interactive livestream experience and display user engagement transparently.

6. User Rights

As a data subject, you have the right to request information about your stored data, request correction or deletion, or object to the processing at any time. Please contact the responsible party listed above for inquiries.

7. No Tracking / Cookies

This website does not use cookies, trackers, analytics tools or advertising networks. No behavioral or cross-site tracking occurs.

8. Changes to This Policy

This privacy policy may be updated at any time to reflect legal changes or changes in data processing. The latest version is always available on this page.
